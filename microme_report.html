Ablation · M3

Muon beats AdamW on the same budget

The speedrun community's headline optimizer, reimplemented in ~60 lines. On identical data and a fixed token budget, Muon reaches every loss target with fewer tokens — the classic sample-efficiency win, confirmed on our own hardware.

The main run · M4

Overtraining pays

The 125M base model, trained on 3 billion FineWeb-Edu tokens — roughly 24× the "compute-optimal" point. Deliberately over-trained, the SmolLM recipe: for a model you'll actually use, tokens-per-parameter far beyond optimal keeps paying off. It cleared the ≤3.4 gate at 26% and kept falling to 2.97.

The wall · post-M5

Fine-tuning can't add knowledge

The chat model was fluent and followed conversations — but confidently wrong on facts ("2 + 2 = 8", "the largest planet is the Kuiper Belt"). Could better fine-tuning data fix it? Three attempts said no.

Fine-tune recipeResult
SmolTalk (base → chat)Fluent, rambly. Some facts right (Shakespeare ✓), most wrong.
+ Dolly 15k, 4 epochsDegraded — repetition loops, facts regressed.
+ Dolly∪SmolTalk, gentleCoherence recovered; a few facts flipped right — but lateral overall.

The lesson, proven three ways: SFT changes which facts land, it doesn't add reliable knowledge to 125M parameters. Style lives in the weights; facts have to live somewhere else.

The honest fix

RAG: retrieval, not more training

Facts go in a lookup; the model just handles language. A 30-fact store, dense-embedding retrieval, and a grounded prompt turned the worst hallucinations into correct answers — same weights, no retraining.

QuestionNo RAG — the model guessingWith RAG — grounded
Who wrote Romeo & Juliet?"Pope Julius Caesar wrote it in 15 AD""a play by William Shakespeare"
What is PySpark?"a spark that creates a spark spawn""Apache Spark — distributed processing across a cluster"
What is FastAPI?"a JavaScript library built on .NET""a Python web framework for building APIs"
What is RAG?"a type of data storage""a model retrieves documents and adds them to its prompt"

The retriever found the right fact every time; the model's only job was to say it. That division of labour — language in the weights, facts in retrieval — is the whole point.

What it teaches

Seven things that stopped being jargon

Tokenization

Vocab is a budget

At 125M, a 24k vocab keeps embeddings from eating the parameter budget — a design choice, not a detail.

Architecture

Every block by hand

RMSNorm, RoPE, QK-norm, ReLU², untied embeddings, logit softcap — written out, they stop being acronyms.

Optimization

Geometry matters

Muon's orthogonalized updates beat AdamW measurably — optimizer choice made concrete on a loss curve.

Scaling

Data quality > scale

30M on TinyStories writes coherent English; 24× overtraining keeps paying — felt on the electricity bill.

Post-training

The same ladder

pretrain → SFT → evaluate is the shape of every frontier pipeline, four orders of magnitude smaller.

Limits

Know the ceiling

A 125M model mimics style and tone; it can't be a fact store. Retrieval, not fine-tuning, is the fix.
